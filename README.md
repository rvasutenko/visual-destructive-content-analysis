# VK Destructive Content Detector

Мультимодальная система автоматического выявления деструктивного контента (насилие, порнография, терроризм) в изображениях, публикуемых в сообществах ВКонтакте. Анализ объединяет визуальные признаки, текст из поста, распознанный OCR-текст и детектированные объекты (YOLO). Модель может дообучаться на пользовательском датасете для повышения точности.

---

## Возможности
- Парсинг изображений со стены любого публичного сообщества через VK API.
- Пакетная и асинхронная обработка (многопоточность + GPU-инференс).
- Извлечение текста (EasyOCR) и классификация токсичности (RuBERT).
- Детекция объектов, характерных для деструктивного контента (YOLOv8 nano).
- Мультимодальное слияние признаков для финального вердикта.
- Сохранение результатов в формате JSONL.
- Скрипт для тонкой настройки модели на собственном датасете.

## Требования
- Python 3.10+ (рекомендуется 3.10–3.11)
- Доступ к VK API (сервисный ключ)
- Для GPU‑ускорения: CUDA‑совместимая видеокарта (опционально)

## Установка

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-repo/vk-destructive-detector.git
cd vk-destructive-detector
```

### 2. Создание виртуального окружения
```bash
python -m venv .venv
source .venv/bin/activate   # Linux / macOS
# .venv\Scripts\activate    # Windows
```

### 3. Установка зависимостей
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

> **macOS / M1–M3:** если возникают конфликты OpenMP, задайте переменную окружения:
> ```bash
> export KMP_DUPLICATE_LIB_OK=TRUE
> ```

### 4. Загрузка предобученных моделей
При первом запуске библиотеки автоматически загрузят веса моделей:
- `EfficientNet-B0` (~20 MB)
- `YOLOv8 nano` (~6 MB)
- `RuBERT base cased` (~1.3 GB)
- `EasyOCR` (~100 MB)

Убедитесь, что интернет‑соединение стабильно и на диске достаточно места.

## 🛠 Конфигурация

1. **Получите сервисный ключ VK API** (инструкция в [официальной документации](https://dev.vk.com/ru/api/access-token/getting-started)).
2. Скопируйте файл шаблона конфигурации:
   ```bash
   cp config.example.py config.py
   ```
3. Откройте `config.py` и заполните поле `VK_ACCESS_TOKEN` вашим ключом.
4. При необходимости измените пороги уверенности, пути к словарям и другие параметры.

## Использование

### 1. Сканирование стены сообщества
Загружает последние посты указанного паблика, анализирует изображения и сохраняет результат в JSONL.

```bash
.venv/bin/python run_vk_aprobation.py --screen <screen_name> --posts <N> -o <output.jsonl>
```

**Параметры:**
- `--screen` – короткое имя сообщества (например, `pravdashowtop`).
- `--posts` – количество последних постов для анализа.
- `-o`, `--output` – путь к выходному файлу (по умолчанию `results/wall_scan.jsonl`).

**Пример:**
```bash
.venv/bin/python run_vk_aprobation.py --screen pravdashowtop --posts 30 -o results/pravdashowtop.jsonl
```

Результат – файл с одной строкой JSON на каждое изображение, содержащий предсказание модели, обнаруженные объекты, извлечённый текст и пр.

### 2. Обучение / дообучение модели
Позволяет адаптировать мультимодальный классификатор под собственный размеченный датасет (формат CSV).

```bash
.venv/bin/python train.py --workers 0
```

> **Параметр `--workers 0`** отключает многопроцессорную загрузку данных, что помогает избежать проблем на macOS и Windows.

**Подготовка данных:**
- Создайте папку `data/images/` и поместите туда изображения.
- Создайте CSV‑файл `data/train_labels.csv` со столбцами:
  - `image_filename` – имя файла изображения.
  - `text` – сопроводительный текст (можно пустой).
  - `label` – 1 (деструктивный) или 0 (безопасный).

После обучения модель сохраняется в `models/fusion_model.pt`.

### 3. Проверка локального изображения
Проверяет одно изображение, сохранённое на компьютере, без обращения к VK.

```bash
.venv/bin/python test_local.py
```

Скрипт загружает изображение из текущей директории с именем `test_image.jpg`. Вы можете изменить путь в самом скрипте или передать путь к файлу в качестве аргумента (при необходимости доработайте скрипт).

Результат – JSON с подробным выводом в консоль.
